# PC 첫 화면 배경 영상 만들기

PC(1024px 이상) 첫 화면 뒤에서 소리 없이 반복되는 24초 영상의 원본과 만드는 도구예요. 결정 내용은 `docs/intent/hankkeut-bg-video.md`에 있어요.
앱에서 쓰는 파일은 `munteok/media/start-bg.mp4`(먼저 고름), `start-bg.webm`(H.264를 못 트는 브라우저용), `start-bg.jpg`(포스터, 영상 첫 장면)이고, 첫 화면에 까는 코드는 `munteok/js/bgvideo.js`, `munteok/css/bgvideo.css`예요.

## 장면 (한 바퀴 24초, 1920×1080, 30장/초)

첫 화면의 글과 예시 영수증이 가운데에 있어서, 영상 이야기는 화면 위·아래 띠에서만 해요. 앱은 영상을 화면 높이에 맞춰 가운데에 두므로, 화면 높이가 730px 이상이면 위 띠는 위쪽 막대와 제목 사이에, 아래 띠는 첫 화면 내용 아래에 와요.

| 초 | 띠 | 장면 |
|---|---|---|
| 0.9~4.7 | 위 | 카페 예시 공고를 입력 칸에 타이핑하듯 붙여 넣기 |
| 4.85~8.3 | 위 | 보내기 → "AI가 공고를 읽고 있어요" → 근무시간·시급·4대보험에 형광펜 |
| 8.7~12.4 | 아래 | 영수증이 올라오며 버는 돈 131만 − 보험료 13만 − 줄어드는 정부 지원 37만 = 남는 돈 81만 원 |
| 12.4~18.7 | 아래 | 근무시간 막대(막대 길이 = 버는 돈)가 주 24 → 15 → 18시간으로 움직이며 남는 돈 81 → 74 → 84만 원 |
| 19.5~21.9 | 아래 | "한 끗 차이로 달라지는 내 돈, 일하기 전에 확인해요" |
| 21.9~24 | 위 | 한끗 로고가 줄어들며 다시 입력 칸이 됨 → 0초 장면과 같아져 끊김 없이 이어짐 |

영상 파일은 7.9초 장면(형광펜을 다 칠한 공고)부터 시작해요. 그래서 포스터 한 장만 보는 사람(동작 줄이기)에게도 "공고를 올리면 AI가 조건을 읽는다"가 보여요.
숫자는 카페 예시를 계산 엔진에 넣은 값이에요(`node nums.mjs`로 다시 낼 수 있어요). 숫자는 세어 올라가지 않고, 바뀔 때 흐려졌다 나타나요.

## 다시 만들기

1. 헤드리스 Chrome을 띄워요(포트는 아무거나): `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --remote-debugging-port=9444 --user-data-dir=/tmp/hk-chrome about:blank`
2. 장면을 찍어요(1~2분): `CDP_PORT=9444 node render.mjs /tmp/hk-frames 30 7.9`
   - 몇 장면만 볼 때: `CDP_PORT=9444 node render.mjs /tmp/hk-stills --at 3,10.5,17.6`
3. 묶어요: `./encode.sh /tmp/hk-frames ../../munteok/media`

글꼴은 Pretendard(앱과 같은 CDN)만 써서 인터넷 연결이 필요해요. 색은 BT.709로 표시해 두어, 영상 바탕(#F2F4F6)이 앱 바탕과 같아 영상 가장자리가 보이지 않아요.
