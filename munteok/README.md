# 문턱

청년이 알바 공고나 제안 메시지의 조건을 넣으면, 그 일을 했을 때 넘게 되는 제도 기준선과 손익을 계산하고 넘지 않는 근무 조건을 찾아 주는 서비스.

## 실행

설치가 필요 없다. 이 폴더를 정적 웹 서버로 열면 된다.

```bash
python3 -m http.server 8770 --directory munteok
```

- 앱: http://localhost:8770/
- 규칙 엔진 테스트: http://localhost:8770/tests/

터미널 테스트: `node tests/run.mjs` (또는 `npm test`)

`index.html`을 파일로 직접 열면 규칙표를 불러오지 못한다. 반드시 서버로 연다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `data/rules.json` | 규칙표. 기준 금액, 근거 출처, 적용 연도, 확인일, 확인 수준 |
| `js/engine.js` | 계산 엔진. 급여, 제도별 판정, 대안 탐색. 화면과 분리된 순수 함수 |
| `js/samples.js` | 시연용 가상 샘플 3개 |
| `js/app.js` | 화면 흐름 |
| `css/style.css` | 휴대폰 우선 화면 스타일 |
| `tests/` | 엔진 기대값 테스트 (브라우저에서 실행) |

## 현재 되는 것

- 가상 샘플 3개와 직접 입력으로 시작부터 결과까지 전체 흐름
- 추출 확인(항목별 확정·추정·확인 필요), 추가 질문, 내 상황 입력
- 제도 4개 판정: 부모 연말정산 공제(현행·개정안 병기), 건강보험 피부양자, 구직촉진수당, 주 15시간 기준
- 제안 비교: 제안을 3개까지 저장해 같은 규칙으로 계산하고, 월 예상 추가수입, 일한 시간당 금액, 기간 전체 금액, 확인 안 된 조건 수를 나란히 보여준다. 기준마다 앞서는 제안만 표시하고 결론은 내리지 않는다
- 제안마다 시작 전에 고용주에게 물어볼 질문을 만든다(지급 방식, 주휴수당, 기간 등)
- 월별 누적 소득, 근무조건 비교(사용자가 답한 주당 최대 시간 안에서 근무시간을 바꿔 계산), 예상 추가수입이 줄어드는 구간 표시, 선택한 조건에 맞는 요청 문구
- 변화를 급여 증가, 수당 감소, 자격 확인 필요, 소득 신고 필요로 구분해 표시. 기준을 넘었다는 사실과 그 변화의 유불리를 따로 보여준다
- 요약 금액은 "계산 범위 내 예상 추가수입"이며 계산에 넣은 것과 넣지 않은 것을 함께 밝힌다. 부모의 세금 증가액은 근거가 부족해 계산하지 않는다
- 근거와 다음 행동, 해당 없는 제도와 범위 밖 제도 안내, 최저임금 미달 경고

## AI 추출 (api/extract.js)

| 항목 | 내용 |
|---|---|
| 하는 일 | 공고 텍스트나 사진에서 시급, 주당 근무시간, 시작 월, 개월 수, 소득 종류를 뽑고 항목마다 확정·추정·확인 필요와 원문 근거를 붙인다 |
| 하지 않는 일 | 기준선 판정과 금액 계산. 그 일은 브라우저의 `js/engine.js`가 한다 |
| 모델 | `claude-opus-5-5`, effort `low`, 구조화 출력(JSON 스키마)으로 형식을 고정 |
| 안전장치 | 텍스트 4,000자, 사진 약 3MB 제한. 범위를 벗어난 값은 버리고 확인 필요로 바꿈. 일자리 공고가 아니면 거절. 입력 내용은 서버에 저장하거나 기록하지 않음 |
| 실패 시 | 화면에 이유와 재시도 안내를 보여주고 직접 입력이나 샘플로 넘어갈 수 있음 |
| 사진 | 브라우저에서 긴 변 1600px JPEG로 줄여 보냄 |

실행 위치는 Vercel 서버 함수다. 배포 방법은 저장소 맨 위 README의 "AI 서버 배포하기(Vercel)"를 따른다.

## 아직 안 되는 것

- **AI 추출의 실제 동작**: 코드(`api/extract.js`)는 있지만 API 키를 넣은 Vercel 배포 전이라 실제 Claude 호출은 아직 해 보지 못했다. 가짜 서버와 가짜 SDK로 화면 흐름, 오류 처리, 값 정리만 확인했다. 로컬 `python3 -m http.server`에는 서버 기능이 없어 AI 추출 버튼이 실패 안내를 보여준다.
- **AI 에이전트의 대안 탐색과 설명**: 대안 계산 자체는 `searchAlternatives`가 하고 있다. AI가 이 함수를 도구로 호출하고 결과를 설명하는 부분은 연결 전이다.
- **화면 6(입력 요약), 화면 9(대안 상세), 화면 11(내 기록)**: 만들지 않았다. 요약은 내 상황 화면 하단에, 요청 문구는 대안 비교 화면에 넣었다.

## 규칙의 확인 수준

`data/rules.json`의 `verification` 값이 화면 표시 등급을 정한다.

| 값 | 뜻 | 화면 표시 |
|---|---|---|
| `official` | 정부·법령 원문을 직접 확인 | 확정. 금액, 판정, 대안에 사용 |
| `secondary` | 2차 자료 또는 원문 수치로 계산한 값 | 추정. 금액에 쓰되 큰 숫자에서 빼고 따로 표시 |
| `unverified` | 원문을 확인하지 못함 | 확인 필요. 금액, 판정, 대안에 쓰지 않고 "추가 확인 항목"으로만 안내 |

제출 전에 규칙 담당이 원문을 확인하고 값을 고쳐야 하는 항목:

| 항목 | 현재 | 확인할 곳 |
|---|---|---|
| 구직촉진수당 계산식의 2026년 적용 여부 | secondary | 고용24, 고용센터 1350 |
| 2026년 1인 가구 기준 중위소득 60% (1,538,543원) | secondary | 보건복지부 고시 |
| 4대보험 근로자 요율 | secondary | 각 공단 고시 |
| 일용근로소득이 부양가족 소득 요건에서 빠지는지 | unverified | 국세청 126, 소득세법 |
| 사업소득을 경비를 뺀 금액으로 보는지 (부모 공제, 피부양자) | unverified | 국세청, 건강보험공단 |
| 주 15시간 이상이면 직장가입자가 되는지 | unverified | 건강보험공단 1577-1000 |
| 부모 공제 개정안의 국회 통과 여부와 적용 시점 | secondary | 국회, 재정경제부 |
| 범위 밖 제도의 문의처 번호 | 미확인 | 각 기관 |

규칙 값을 바꾸면 `tests/engine.test.js`의 기대값도 손으로 다시 계산해 고친다.

## 계산에서 가정한 것

- 한 달은 4.345주로 계산한다.
- 공고에 적혀 있지 않으면 주휴수당은 시급과 별도로 지급된다고 가정하고 "추정"으로 표시한다. 확인 화면에서 "시급에 이미 포함됨"으로 바꿀 수 있다.
- 입력값은 새로고침해도 남도록 브라우저 탭의 세션 저장소에 둔다. 탭을 닫으면 지워지고 서버로 보내지 않는다.
- 소득세(근로소득 간이세액)는 계산하지 않는다.
- 2026년 규칙으로 한 해(1월~12월)만 계산한다. 해를 넘기는 근무는 올해 분만 계산하고, 빠진 개월 수를 화면에 알려 준다. 2027년 기준은 최저임금(10,700원)만 확정되어 안내용으로만 쓴다.
- 대안 탐색은 주당 근무시간만 바꾼다. 시급과 기간은 그대로 둔다.
- 야간·연장 가산수당은 계산하지 않는다.
