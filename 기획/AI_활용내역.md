① 활용 AI 모델·도구
[서비스] Claude Opus 5.5 API(claude-opus-5-5, Anthropic): 알바 공고 사진·메시지에서 시급, 주당 근무시간, 시작 월, 기간, 소득 종류(근로·일용·사업소득 3.3%), 주휴수당 포함 여부를 정해진 형식(구조화 출력)으로 추출. 서버 코드 완성, 배포 준비 중 [배포 후 "동작"으로 수정].
[개발] Claude Code(Anthropic Claude 모델): 주제 후보 검토와 평가 기준 대조, 공공데이터·법령 조사, 계산 엔진·화면·테스트 코드 작성, 소개서·README 초안. 매니패스트: 요구사항 문서, 기능명세, 유저플로우, 와이어프레임 초안.

② AI 활용 범위와 팀의 기여
AI가 한 일: 주제 후보 제시와 약점 분석, 법령·고시 검색과 요약, 계산 엔진과 화면 코드 초안, 테스트 기대값 작성, 기획 문서와 소개서 초안.
팀이 한 일: 문제 선정과 최종 방향 결정. 첫 기획(채용공고 검증)은 공고 대부분에 급여가 적혀 있지 않다는 점을 팀이 지적해 폐기했다. 문턱에 대해서도 팀이 심사 관점에서 의문을 제기했고, 검토 결과 "일을 줄이라"는 인상이 원인이어서 "받은 제안 비교와 시작 전 준비"로 방향을 바꿨다. 평가 기준은 운영사무국에 직접 문의해 확인했다. 범위도 팀이 정했다(로그인·관리자 화면 제외, 화면 6단계, 계산 제도 4개). 구현본을 검토한 수정 제안서를 바탕으로 우선순위를 정해 미확인 규칙 처리, 비교 화면, 요청 문구를 고쳤다. [수정 제안서 작성자와 역할 분담을 실제 내용으로 보완]

③ API·외부 데이터·오픈소스
API: Anthropic Claude API(조건 추출). 공공데이터 API는 사용하지 않았다.
외부 데이터: 소득세법 기본공제 소득 요건(정책브리핑), 국민건강보험법 시행규칙 별표 1의2(국가법령정보센터), 구직촉진수당 지급액과 계산식(고용노동부), 근로기준법 제18조 제3항 질의회시(고용노동부), 2027년 적용 최저임금 고시(고용노동부). 원문을 읽고 규칙표(rules.json)로 직접 정리했으며, 규칙마다 근거 링크·확인일·확인 수준을 기록했다.
오픈소스: @anthropic-ai/sdk(Apache-2.0), zod(MIT). 배포: GitHub Pages, GitHub Actions. 시연 데이터: 직접 만든 가상 공고 3건. 상세 출처·라이선스는 소개서 별첨 「활용한 외부 자원·출처」 표 참조.

④ 검증 및 한계 대응
- 금액 계산은 AI가 하지 않는다. 규칙표를 읽는 코드가 계산하고, AI는 그 값을 바꾸지 않는다.
- AI가 만든 계산 코드는 손으로 계산한 기대값 105건으로 검증했다. 그 과정에서 대안 탐색의 정의 오류, 일당 소득을 미확인 규칙으로 "자격 유지"라고 판정하던 오류를 찾아 고쳤다.
- 이를 계기로 확인 수준 규칙을 만들었다. 원문을 확인한 규칙만 금액과 판정에 쓰고, 2차 자료 값은 "추정"으로 따로 표시하며, 원문 미확인 규칙은 "추가 확인 항목"으로만 안내한다.
- AI 기획 도구가 와이어프레임에 지어낸 기준 금액, 법 조문, 개정안을 발견해 모두 버리고, 수치는 원문으로 확인한 규칙표만 쓰도록 했다.
- AI 검색 결과의 수치는 원문으로 다시 확인했다. 예: 오픈소스 라이선스를 설치된 패키지 정보로 대조해 Apache-2.0으로 바로잡았다.
- 추출 결과에는 항목마다 원문 근거와 확인 수준을 붙이고 사용자가 고칠 수 있다. 모르는 값은 추측하지 않고 되묻는다. 범위를 벗어난 값은 버리고, AI 호출이 실패하면 직접 입력과 샘플로 이어 간다.
- 실제 개인정보는 AI에 입력하지 않았고 시연은 가상 샘플로만 했다. 입력값은 서버에 저장하지 않는다.
- 남은 한계: AI 추출의 실제 정확도는 배포 후 가상 공고로 측정 예정 [측정치로 교체]. 수당 계산식 등 규칙 7건은 원문 확인 전이라 추정 또는 확인 항목으로 표시된다. 2026년 한 해만 계산하며, 결과는 참고용으로 행정기관의 판단을 대체하지 않는다.
